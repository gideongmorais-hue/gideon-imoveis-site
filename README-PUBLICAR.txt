GIDEON IMOVEIS - COMO PUBLICAR NA VERCEL

1. Entre no GitHub e clique em New repository.
2. Nome do repositorio: gideon-imoveis-site
3. Deixe como Public e clique Create repository.
4. Na pagina do repositorio, clique em uploading an existing file.
5. Arraste TODOS os arquivos e pastas deste projeto (nao arraste apenas o ZIP).
6. Clique em Commit changes.
7. Acesse a Vercel e clique Add New > Project.
8. Importe o repositorio gideon-imoveis-site.
9. Framework Preset: Other.
10. Clique Deploy.
11. Depois do site publicado: Settings > Domains.
12. Adicione gideonimoveis.com.br e www.gideonimoveis.com.br.
13. A Vercel mostrara os registros DNS que devem ser copiados para o Registro.br.
14. No Registro.br: Dominios > gideonimoveis.com.br > DNS > Editar Zona.
15. Adicione exatamente os registros informados pela Vercel.
