Instruções para ativar o painel

Importante: o site abre e funciona imediatamente. Sem Supabase, o painel fica em modo local de teste. Para cadastrar imóveis que apareçam publicamente para todos, faça a configuração abaixo uma única vez.

1. Criar as tabelas

No Supabase, abra SQL Editor, cole todo o conteúdo do arquivo SUPABASE-SETUP.sql e execute.

2. Criar seu usuário administrador

No Supabase, abra Authentication → Users → Add user. Cadastre seu e-mail e uma senha forte.

3. Conectar o site

Abra o arquivo js/config.js no Bloco de Notas e substitua:

COLE_AQUI_A_URL_DO_SUPABASE
COLE_AQUI_A_CHAVE_PUBLICA_DO_SUPABASE

Use apenas a Project URL e a Publishable Key. Nunca coloque a senha do banco nem uma Secret Key no site.

4. Publicar

Envie todos os arquivos e pastas para o repositório GitHub conectado à Vercel. O painel ficará em /admin.html.
